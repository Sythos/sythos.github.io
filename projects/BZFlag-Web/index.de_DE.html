BZFlag-Web

Über dieses Projekt

Der BZFlag Web Client ist ein unabhängiger Browser-Client und ein Node.js-Gateway für das BZFlag-Ökosystem. Der Client ist eine statische HTML5-Anwendung, deren TypeScript-Quellen zu browserfähigem JavaScript kompiliert werden; das Gateway stellt eine eng gefasste, richtliniengesteuerte WebSocket-Grenze zu offiziellen BZFlag-Servern bereit und erhält dabei die nativen TCP/UDP-Transporte. Die öffentliche Implementierung zielt auf BZFlag/BZFS 2.4.31, unterstützt WebGPU mit WebGL2-Fallback und ist weder eine offizielle BZFlag-Version noch ein allgemeiner Proxy.

BZFlag-Web

Acerca de este proyecto

BZFlag Web Client es un cliente de navegador independiente y una puerta de enlace Node.js para el ecosistema BZFlag. El cliente es una aplicación HTML5 estática cuyas fuentes TypeScript se compilan a JavaScript listo para el navegador; la puerta de enlace ofrece una interfaz WebSocket acotada y controlada por políticas hacia los servidores oficiales de BZFlag, conservando los transportes TCP/UDP nativos. La implementación pública está orientada a BZFlag/BZFS 2.4.31, admite WebGPU con fallback a WebGL2 y no es ni una versión oficial de BZFlag ni un proxy de propósito general.

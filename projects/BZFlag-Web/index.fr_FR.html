BZFlag-Web

À propos de ce projet

BZFlag Web Client est un client indépendant pour navigateur et une passerelle Node.js pour l’écosystème BZFlag. Le client est une application HTML5 statique dont les sources TypeScript sont compilées en JavaScript prêt pour le navigateur ; la passerelle fournit une interface WebSocket restreinte et contrôlée par des politiques vers les serveurs BZFlag officiels, tout en préservant les transports TCP/UDP natifs. L’implémentation publique cible BZFlag/BZFS 2.4.31, prend en charge WebGPU avec repli sur WebGL2 et n’est ni une version officielle de BZFlag ni un proxy à usage général.

BZFlag-Web

Informazioni sul progetto

BZFlag Web Client è un client browser indipendente e un gateway Node.js per l’ecosistema BZFlag. Il client è un’applicazione HTML5 statica le cui sorgenti TypeScript vengono compilate in JavaScript pronto per il browser; il gateway fornisce un confine WebSocket ristretto e controllato dalle policy verso i server BZFlag ufficiali, preservando i trasporti TCP/UDP nativi. L’implementazione pubblica punta a BZFlag/BZFS 2.4.31, supporta WebGPU con fallback a WebGL2 e non è né una release ufficiale di BZFlag né un proxy generico.

BZFlag-Web

このプロジェクトについて

BZFlag Web Client は、BZFlag エコシステム向けの独立したブラウザクライアント兼 Node.js ゲートウェイです。クライアントは、TypeScript ソースをブラウザー向け JavaScript にコンパイルする静的な HTML5 アプリケーションであり、ゲートウェイはネイティブな TCP/UDP トランスポートを維持しながら、公式 BZFlag サーバーとの接続にポリシーで制御された限定的な WebSocket 境界を提供します。公開実装の対象は BZFlag/BZFS 2.4.31 で、WebGL2 フォールバック付きの WebGPU をサポートしますが、公式 BZFlag リリースでも汎用プロキシでもありません。

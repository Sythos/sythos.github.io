BZFlag-Web

프로젝트 소개

BZFlag Web Client는 BZFlag 생태계를 위한 독립적인 브라우저 클라이언트이자 Node.js 게이트웨이입니다. 클라이언트는 TypeScript 소스를 브라우저용 JavaScript로 컴파일하는 정적 HTML5 애플리케이션이며, 게이트웨이는 네이티브 TCP/UDP 전송을 유지하면서 공식 BZFlag 서버에 정책으로 제어되는 제한적인 WebSocket 경계를 제공합니다. 공개 구현은 BZFlag/BZFS 2.4.31을 대상으로 하며 WebGL2 폴백을 지원하는 WebGPU를 제공하지만, 공식 BZFlag 릴리스도 범용 프록시도 아닙니다.

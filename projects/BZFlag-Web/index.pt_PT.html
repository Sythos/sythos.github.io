BZFlag-Web

Sobre este projeto

BZFlag Web Client é um cliente de navegador independente e um gateway Node.js para o ecossistema BZFlag. O cliente é uma aplicação HTML5 estática cujas fontes TypeScript são compiladas para JavaScript pronto para o navegador; o gateway disponibiliza uma fronteira WebSocket restrita e controlada por políticas para os servidores BZFlag oficiais, preservando os transportes TCP/UDP nativos. A implementação pública visa BZFlag/BZFS 2.4.31, suporta WebGPU com fallback para WebGL2 e não é um lançamento oficial do BZFlag nem um proxy de uso geral.

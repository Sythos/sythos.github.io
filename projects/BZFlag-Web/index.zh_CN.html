BZFlag-Web

关于此项目

BZFlag Web Client 是面向 BZFlag 生态的独立浏览器客户端和 Node.js 网关。客户端是一个静态 HTML5 应用，其 TypeScript 源代码会编译为可在浏览器中运行的 JavaScript；网关在保留原生 TCP/UDP 传输的同时，为连接官方 BZFlag 服务器提供范围受限且由策略控制的 WebSocket 边界。公开实现面向 BZFlag/BZFS 2.4.31，支持带 WebGL2 回退的 WebGPU，既不是官方 BZFlag 发行版，也不是通用代理。

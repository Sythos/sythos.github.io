ClasseViva Dashboard

Über dieses Projekt

CVV Dashboard ist eine benutzerdefinierte Integration und eine Lovelace-Karte für Home Assistant. Sie liest Daten aus einem ClasseViva-Konto und zeigt Noten, Durchschnittswerte, Mitteilungen, Agenda-Einträge, Notizen, Zeugnisse und Hausaufgaben. Für jeden Schüler erstellt sie vier Home-Assistant-Kalender.

Cordiale

Informazioni sul progetto

Cordiale è un client desktop nativo e leggero per Grappa, realizzato con Rust e Slint. Parla il protocollo REST e Phoenix Channels/WebSocket di Grappa, non IRC puro: puoi chattare senza portarti dietro un intero motore browser. La GUI aspetta ancora la sua prima uscita con un server live. Per il retroscena Grappa-IRC: vjt/grappa-irc.

Acerca de este proyecto

Sythos Barcode Universal es un SDK de JavaScript/TypeScript de código abierto, distribuido bajo la licencia MIT, para generar, detectar, decodificar y renderizar códigos de barras 1D y 2D. No tiene dependencias en tiempo de ejecución y funciona en navegadores, Web Workers y Node.js o Bun. El repositorio incluye código fuente legible, bundles ESM/IIFE y documentación sobre la API, los formatos, los flujos de trabajo con imágenes y cámara, ejemplos y guías para distintas plataformas.

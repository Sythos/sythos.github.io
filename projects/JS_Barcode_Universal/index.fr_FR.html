À propos de ce projet

Sythos Barcode Universal est un SDK JavaScript/TypeScript open source sous licence MIT permettant de générer, détecter, décoder et effectuer le rendu de codes-barres 1D et 2D. Il n’a aucune dépendance à l’exécution et fonctionne dans les navigateurs, les Web Workers et avec Node.js ou Bun. Le dépôt fournit un code source lisible, des bundles ESM/IIFE et une documentation couvrant l’API, les formats, les workflows d’image et de caméra, les exemples et les guides par plateforme.

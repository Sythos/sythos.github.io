À propos de ce projet

Battlezone Online est un jeu de chars multijoueur en temps réel construit avec Node.js, WebSockets et Three.js. Sa documentation couvre l’installation avec Docker et depuis les sources, les versions pour plusieurs architectures, les serveurs de test publics, les cartes persistantes, le mode VR WebXR, les commandes et la disponibilité du code source sous AGPLv3. Sythos/bzo est un fork public de timriker/bzo.
